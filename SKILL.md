# AI Comic Dialogue — High-Quality Character Conversations for AI漫剧

Use this skill to generate or refine character dialogues that feel natural, distinctive, and cinematic for AI-generated short comic dramas. Focus on character voice, subtext, conflict, and short-form video suitability (concise lines that sync with visuals and emotion).

## Core Workflow

1. **Establish Character Voices**
   - Create or load a brief character profile for each speaker: core personality, speech habits (formal/casual, verbose/terse, slang, catchphrases), emotional baseline, relationship to others, current goal/conflict in the scene.
   - Ensure every line reflects that voice. Different characters must sound different even without tags.

2. **Define Scene Purpose**
   - Clarify what the scene must achieve: reveal information, escalate conflict, show character change, deliver emotional beat, or set up next visual gag/action.
   - Dialogue should advance at least one of these; cut pure small talk unless it builds tension or character.

3. **Draft with Constraints**
   - Keep individual lines short (usually under 20 Chinese characters or equivalent) for AI voice and short video pacing.
   - Prefer subtext over direct statement. Characters rarely say exactly what they mean.
   - Include action beats or visual cues that can pair with dialogue (e.g., "turns away", "forces a smile").
   - Build toward a clear emotional peak or punchline suitable for a 15-60s clip.

4. **Refine for Quality**
   - Check consistency: Does this line match the character's established voice?
   - Improve naturalness: Add interruptions, incomplete sentences, reactions, or specific details instead of generic responses.
   - Strengthen conflict or desire: What does each character want from this exchange? Make it visible in the words.
   - Test readability aloud: If it sounds stiff or "AI-written", rewrite.
   - Verify visual synergy: Can this dialogue be illustrated effectively in AI image/video generation?

5. **Output Format**
   Prefer clean script format:
   ```
   【场景：xxx】
   角色A：（动作/表情）对话内容
   角色B：（反应）对话内容
   ```
   Or bilingual if requested. Always note key emotional tone for voice generation.

## Key Principles

| Principle | Do | Avoid |
|-----------|----|-------|
| Character Voice | Distinct rhythm, vocabulary, attitude per character | Everyone sounds the same |
| Subtext | Hint at true feelings through deflection or action | Direct "I am angry because..." |
| Conflict | Each line pushes or resists the other character's goal | Agreeable, flat exchanges |
| Economy | One strong idea per line; cut filler | Long monologues or info dumps |
| Emotion | Clear peak that can be visualized and voiced | Neutral or vague delivery |
| Short-form Fit | Hook early, payoff within the clip length | Slow buildup unsuitable for AI漫剧 |

## Common Refinement Techniques

- **Specificity**: Replace "你怎么这样" with a concrete accusation tied to the plot.
- **Reaction first**: Let characters react emotionally before explaining.
- **Incomplete thoughts**: Use trailing off, interruptions, or changing topic to show real conversation.
- **Physical tie-in**: Pair key lines with a visual that AI can generate (clenched fist, tear, smirk, etc.).
- **Contrast**: Juxtapose polite words with hostile action, or vice versa.

## Common Issues

| Problem | Symptom | Fix |
|---------|---------|-----|
| Stiff dialogue | Sounds like narration or textbook | Read aloud; add contractions, interruptions, specific details |
| Same voice | All characters interchangeable | Strengthen unique speech habits and goals |
| No stakes | Conversation could be removed without loss | Clarify what each character wants and make them fight for it |
| Too long | Lines exceed short-video pacing | Split or cut to the essential emotional core |
| Generic emotion | "我好难过" without context | Show the reason through concrete memory or accusation |

When refining existing dialogue, always quote the original lines and show the improved version with a brief note on what changed and why.
