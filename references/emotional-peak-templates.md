# 情绪峰值设计模板（Emotional Peak Templates）

短视频漫剧必须在 15-40 秒内有明确情绪峰值。以下模板可直接套用。

## 1. 压抑后爆发（虐恋 / 冷战）
- 前 70% 台词极短、回避、动作小
- 最后 1-2 句突然变长或直接撞出真心话
- 配合动作：撮住手腕 / 眼泪掉下来 / 转身离开

**示例：**
女：（低声）……随你。
男：（走向电梯）
女：（突然提高声音）你就这么走了？！

## 2. 打脸反转（重生 / 爽文）
- 前半反派自以为占上风
- 最后一句用事实/证据一击命中
- 配合动作：拍合同 / 亮出证据 / 微笑

**示例：**
男：你还能怎么样？
女：（把手机亮到他面前）这是你三年前签的。
男：（脸色变了）

## 3. 甜宠小高潮
- 用动作代替直接表白
- 最后一句留白或反问，让观众自己补完
- 配合动作：盖外套 / 拉住衣角 / 低头笑

**示例：**
男：（把伞倾向她）
女：（盯着伞）你自己不打么？
男：（轻声）……你先。

## 4. 系统流吐槽高潮
- 系统说冷冰冰的规则
- 主角用一句人话破掉系统的“正确”
- 配合动作：盯着天花板 / 开始收拾东西

## 使用提示
> 按“压抑后爆发”模板写这段对话的最后两句，并加上可视化的动作。
