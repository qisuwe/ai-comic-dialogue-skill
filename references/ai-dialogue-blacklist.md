# AI 味对白黑名单与改法

以下是中文 AI 漫剧常见僵硬句式，遇到就重写。

## 黑名单（优先删除或改写）

| 僵硬句 | 为什么坏 | 改法方向 |
|--------|--------|----------|
| “我明白你的意思了” | 空洞、无信息 | 直接做出反应或提出具体条件 |
| “这件事没那么简单” | 说了等于没说 | 说出难在哪里 |
| “其实我……” | 过度完整解释 | 删掉“其实”，改成动作或不完整句 |
| “不过我觉得……” | 拖沓 | 直接说观点或反问 |
| 每句都带“其实/只不过/不过” | 口头禅 | 随机删掉 70% |
| “你知道吗？”无力攻击 | 假设问 | 改成具体指控 |
| 长篇解释动机 | 信息堆砌 | 拆成短句交锋 |
| “我不会让你受伤的” | 空泛承诺 | 改成具体行动 |

## 快速检查
写完后搜这些词：其实、不过、只不过、我明白、没那么简单、你知道的。
命中就重写该句。

## 改写口诀
- 把解释改成动作
- 把结论改成问题
- 把完整句改成不完整句或中断
- 把情感词改成具体事物
