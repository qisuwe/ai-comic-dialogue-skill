# 与视频模型配合提示（Video Model Tips）

写对白时就考虑后续生成（Seedance、即梦、MiniMax H3 等）。

## 台词书写规范
- 每句台词后带简短动作：（转身）（盯着他）（撮紧衣角）
- 情绪峰值句必须有可视化动作
- 避免过长句（超过 20 字容易被截断或赶读）

## 推荐格式（方便拆镜）
```
角色A：（动作）台词
角色B：（反应动作）台词
```

## 常见问题与解法
| 问题 | 原因 | 解法 |
|------|------|------|
| 台词被截断 | 句子太长 | 拆成两句，中间加动作 |
| 角色说话无表情 | 只有台词没动作 | 每句加 1 个可视化动作 |
| 情绪不够 | 峰值句太平 | 用情绪峰值模板重写最后一句 |
| 多人同时说话 | 模型容易乱 | 一句只让一个人说话 |

## 快速检查清单
- [ ] 每句都有动作或表情提示
- [ ] 最强情绪句在片段后半
- [ ] 没有超过 20 字的单句
- [ ] 角色说话习惯一致
